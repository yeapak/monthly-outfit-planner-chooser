# 월간 셋업 — 세미정장 코디 캘린더

남성·여성용 세미정장 코디를 달력의 날짜별로 보여 주는 웹앱입니다. 2026년 9월부터 2027년 12월까지의 옷차림과 간단한 선택 이유를 확인할 수 있습니다.

## 사용 방법

1. 화면 오른쪽 위에서 **남성/여성**과 **연도**를 고릅니다.
2. 보고 싶은 **월**을 누르면 그 달의 모든 날짜별 코디, 간단한 선택 이유, 핵심 의류 목록이 표시됩니다.
3. **이달 코디 인쇄하기** 버튼으로 현재 달의 내용을 인쇄할 수 있습니다.

이 프로젝트는 별도 설치나 서버가 필요 없는 정적 웹사이트입니다. GitHub Pages에서는 이 폴더의 내용을 그대로 올리면 됩니다.
